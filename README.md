# Cursor Skills

Repositório para versionar e compartilhar **Cursor Agent Skills**.

## Estrutura

```
skills/
  <skill-name>/
    SKILL.md          # obrigatório
    reference.md      # opcional
    examples.md       # opcional
    scripts/          # opcional
```

## Como usar

1. Crie uma pasta em `skills/<nome-da-skill>/`
2. Adicione um `SKILL.md` com frontmatter YAML (`name`, `description`)
3. No Cursor, copie a skill para o Agent Store pessoal ou para `.cursor/skills/` do projeto
